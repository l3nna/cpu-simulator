# CPU Simulator

A simulation tool designed to demonstrate and visualize the core concepts of computer architecture, the fetch-decode-execute cycle, and CPU operations.

---

## Overview

**CPU Simulator** provides an interactive environment to simulate and test various CPU operations, registers, memory, and instruction cycles. This project helps in understanding how low-level hardware interacts with code and executes basic computer instructions.

---

## Features

- **Fetch-Decode-Execute Cycle:** Simulates the fundamental operational cycle of a CPU.
- **Memory & Register Management:** Visualizes contents and state updates of internal registers (e.g., Accumulator, Program Counter, Instruction Register) and RAM.
- **Instruction Execution:** Supports basic arithmetic, logical, and control transfer operations.
- **State Visualization:** Provides real-time feedback on CPU state changes during execution.
